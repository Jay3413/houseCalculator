# house1 — 房貸試算程式

簡短說明
- `house1` 是一個以 Windows Forms (C#) 建立的房貸試算小工具，用於計算貸款相關數值並以格式化方式顯示結果。

主要功能
- 計算貸款本金（房屋總價減自備款）。
- 支援自備款輸入為「百分比」或「金額」。
- 支援寬限期（僅利息）並計算攤還期內的本利攤還。
- 結果只輸出：貸款總金額、每月應繳金額(本+息)、首期利息、首期本金、總利息支出、總還款金額（均格式化為千分位、2 位小數）。

開發環境 / 需求
- 開發語言：C# (語言等級 7.3)
- 目標框架：.NET Framework 4.7.2
- 建議 IDE：Microsoft Visual Studio（支援 Windows Forms）

如何編譯與執行
1. 使用 Visual Studio 打開 `house1` 專案資料夾。
2. 建置（Build）專案：`Build -> Build Solution`。
3. 執行（Run）專案：`F5` 或 `Ctrl+F5`。

使用說明（介面項目）
- `房屋總價`：輸入房屋總價（當地貨幣）。
- `自備款`：輸入自備款（視 `百分比 (%)` 或 `金額` 模式而定）。
- `年利率 (%)`：輸入年利率（例如：2.15）。
- `貸款年限 (年)`：貸款總年數。
- `寬限期 (年)`：選填，若 > 0 則在寬限期內只支付利息。
- 按下 `試算` 後，結果會在下方結果區顯示（僅包含要求的幾項，且已格式化）。

設計/外觀
- 使用 `Segoe UI` 為主要字型，結果區使用等寬字型 `Consolas` 提高對齊可讀性。
- 視窗已設定為固定對話框，並調整控制項間距與顏色以提升可視性。

修改程式碼提示
- 若要更改輸出內容或格式，請編輯 `Form1.cs` 中的 `btnCalculate_Click` 方法。
- 若要調整 UI 元件佈局或樣式，請編輯 `Form1.Designer.cs`（或使用 Visual Studio 設計工具進行調整）。
